# Stoker dam break onto a wet bed (analytic)

Depth \`hl\` upstream, \`hr\` (\> 0) downstream: rarefaction, constant
state, then a shock moving downstream.

## Usage

``` r
dambreak_stoker(x, t, hl, hr, x0 = 0, g = 9.81)
```

## Arguments

- x:

  positions (m)

- t:

  time (s), \> 0

- hl, hr:

  upstream and downstream depths

- x0:

  dam position

- g:

  gravity
