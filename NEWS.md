# shallows 0.1.0.9003

* Raster input and output now use gdalraster instead of terra, and plots use
  ximage. Both are in Suggests; terra is no longer used.
* Grids follow `gdalraster::read_ds()`: a row-major vector with a `gis`
  attribute (bbox, dim, srs). `ximage::ximage()` plots one directly.
  Extents in states are `c(xmin, xmax, ymin, ymax)`, the ximage convention.
* Breaking: `sw_rast()` is replaced by `sw_frames()` (a list of grids, one
  per output time) and `sw_write()` (multi-band GeoTIFF with band
  descriptions and times).
* Breaking: `sw_generate()` returns a grid by default (`as = "grid"`)
  instead of a SpatRaster, and `sw_extract()` returns the bed as a grid with
  a `source` attribute instead of a two-layer SpatRaster.
* `sw_from_rast()` takes a file or GDAL source name, a
  `gdalraster::GDALRaster`, or a grid. `sw_coriolis()` takes a state or grid
  with a CRS.
* New `sw_matrix()` gives a grid as a matrix. `sw_state()`, `sw_fill_lake()`
  and `sw_fill_sea()` accept grids directly.
* `inst/examples/mcrobies-storm.R` uses gdalraster (warp, hillshade, GeoTIFF
  output) and ximage.

# shallows 0.1.0.9002

* New vignette, "Shallow water on raster grids with shallows": the model,
  setting up and reading a run, dam breaks and convergence, lake at rest,
  wetting and drying in Thacker's bowl, rain and the water budget, Earth
  rotation, rasters in and out, and the R reference scheme.
* pkgdown site at <https://hypertidy.github.io/shallows/>, built and
  deployed by GitHub Actions.

# shallows 0.1.0.9001

* The C++ interface now uses cpp11 instead of Rcpp. cpp11 is header only,
  so the package has no runtime dependency on it; the solver kernel is
  unchanged and results are identical.
* `sw_run()` coerces its inputs to the types the compiled code needs, so
  integer matrices are accepted as before.
* NAMESPACE is now generated by roxygen2.
* README is built from `README.Rmd`, with live examples (Stoker dam break,
  lake at rest, breached reservoir).
* Added a contributor code of conduct.

# shallows 0.1.0

* Two-dimensional shallow water solver on regular grids: HLL fluxes,
  hydrostatic reconstruction, first or second order, wetting and drying,
  Manning friction, rain, Coriolis, wall, open and periodic edges, and a
  mass budget on every run.
* Analytic benchmarks (`dambreak_ritter()`, `dambreak_stoker()`,
  `thacker_bowl()`), the plain R reference scheme `sw_run_r()`, terrain
  generation and extraction, and terra raster input and output.
